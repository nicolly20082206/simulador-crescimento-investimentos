# 📊 Simulador de Crescimento de Investimentos

## 📖 Sobre o Projeto

Este projeto foi desenvolvido para simular o crescimento de uma reserva financeira ao longo dos anos por meio de investimentos regulares e da aplicação de juros compostos.

A planilha permite visualizar de forma clara a evolução do patrimônio acumulado, ajudando no planejamento financeiro e na compreensão do impacto dos investimentos de longo prazo.

---

## 🎯 Objetivos

- Simular o crescimento de uma reserva financeira.
- Aplicar o conceito de juros compostos.
- Visualizar resultados por meio de gráficos.
- Organizar informações de forma clara e profissional.
- Facilitar a análise financeira do usuário.

---

## 📈 Funcionalidades

✅ Cálculo automático dos rendimentos

✅ Simulação de aportes periódicos

✅ Evolução patrimonial ao longo dos anos

✅ Gráfico de crescimento financeiro

✅ Destaque visual para resultados importantes

✅ Formatação profissional da planilha

---

## 🎨 Formatações Aplicadas

- Cabeçalhos em negrito
- Cores para destacar informações importantes
- Formatação monetária em Real (R$)
- Bordas para melhor organização dos dados
- Gráfico de linha para visualização do crescimento dos investimentos
